# 可信发布门禁

## 1. 敏感信息

README、代码块、终端输出、徽章、截图像素和图片元数据均属于扫描范围

任何视觉资源还需要按照 [视觉隐私与脱敏协议](visual-privacy.md) 检查像素、SVG 源码、文件元数据和外部请求

禁止公开以下内容：

- 真实部署地址、内部域名和带路径的管理入口
- 用户标识、邮箱、头像、账户菜单、通知和组织内部名称
- 账号、密码、访问令牌、应用程序接口密钥、私钥和连接字符串
- 私有网络地址、内部主机名、本地绝对路径和生产目录结构
- 未授权的客户名称、采用者标志、赞助商标志和用户评价

示例地址使用 `example.com` 或 `.invalid` 保留域名，示例账户使用明确标注的合成值

## 2. 截图处理

- 第一步，使用专用演示环境和合成数据重新生成画面

- 第二步，裁去浏览器栏、系统托盘、账户区域和无关桌面内容

- 第三步，检查图片像素中的文字、头像、二维码、路径、网址和通知

- 第四步，删除作者、位置、设备、软件和缩略图等图片元数据

- 第五步，在亮色和暗色背景复核脱敏区域与替代文本

模糊和遮挡可能保留轮廓或被误裁，优先重新生成合成画面

## 3. 声明证据

版本来自发布记录或包元数据，兼容范围来自测试配置，质量状态来自当前检查，许可证来自仓库原文

性能声明需要提供完整复现条件：

- 测试硬件和软件版本
- 输入数据和样本量
- 比较对象和复现命令
- 测试结果的更新时间

测试没有运行时写明未执行，测试失败时写明失败范围，测试通过时写明命令和运行对象

路线图、讨论和计划不代表现有能力，README 需要明确区分已发布、试验中和规划内容

## 4. 高风险入口

项目能够删除数据、执行代码、访问文件系统、调用外部服务或修改生产状态时，风险说明需要靠近触发该风险的操作

安全默认路径优先使用本地、只读、沙箱、最小权限、备份或合成数据

公开演示凭据容易被复制到真实部署，默认模板禁止共享账号和密码

## 5. 发布停止条件

出现未确认秘密、未脱敏截图、无法解释的远程资源、证据不足的数字或双语事实冲突时停止发布

安全负责人或仓库维护者补齐证据后重新执行完整验收

# 头图选择与制作

## 1. 先决定读者需要看什么

头图用于帮助读者识别项目或理解主要交付物，不能承担没有证据的功能承诺

1. 检查现有标志、截图和设计源文件，确认使用权及事实仍然有效
2. 有代表性真实界面时优先使用脱敏截图，图中文字在窄屏太小时裁取核心任务区域
3. 主要价值是命令或调用结果时，使用真实合成输入的终端画面，并在正文提供可复制命令
4. 主要价值是内容或组件关系时，使用可编辑的内容地图或结构图
5. 需要品牌情绪、插画或场景表达时，使用可用的图片生成工具，明确它是品牌插画
6. 图片不能增加理解时，可以省略头图，保留标题与清晰的首次成功入口

## 2. 共同视觉语言

- 同系列保持清楚的留白、简洁形状和少量强调色，各项目保留自己的主色及形象
- 先用宽屏横图构图，在实际窄屏显示宽度复核，过密关系改为竖排或移入正文
- 重要名称与操作入口写在正文，图片不承载唯一的关键文字
- 简单标志和结构图使用可编辑矢量文件，照片与插画使用本地位图
- 默认复用一张在两种背景都可读的图，确有需要才制作亮色和暗色两份
- 双语尽量共享无文字图，必须有文字时生成对应语言版本并核对事实一致

## 3. 生成说明模板

以下内容是制作输入，不能带着占位值出现在最终首页

- 用途：帮助哪类读者识别哪种项目主题
- 类型：品牌插画、关系说明或真实运行截图
- 依据：仓库内哪些文件支持可见对象及其关系
- 画面：主要对象、位置、背景、主色及留白
- 文字：优先无文字，项目名称由正文准确显示
- 禁止内容：虚构界面、性能数字、客户标志、账户信息和未授权素材
- 交付：本地文件、替代文本、下方题注及制作来源

需要照片或插画时使用当前环境的图片生成工具及其适用技能，不把静态结构图强行转换成生成图片

## 4. 选择与验收

候选图先排除事实错误、权利不明和泄露风险，再按主题辨识、关系清晰、窄屏可读及维护成本选择

没有改善读者判断时不追加候选，不以生成数量证明质量

1. 在桌面和窄屏逐张查看真实像素，确认边缘对象没有裁掉
2. 在亮色和暗色背景检查主体对比及透明区域
3. 禁用图片后确认正文仍能完成上手操作
4. 按 [视觉隐私规则](visual-privacy.md) 检查源码、像素和文件元数据
5. 把最终图存入 `docs/assets/readme/`，在相邻制作说明中记录角色、输入依据、工具和修改日期

本仓库选择无文字的文档组合示意图，统一底层形状，变化内部模块，表达共享骨架与灵活组合

它属于结构说明，不是软件运行截图，也不能证明自动审核已经通过
